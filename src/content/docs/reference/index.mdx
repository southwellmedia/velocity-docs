## Component Summary

| Category | Count | Description |
|----------|-------|-------------|
| UI Components | 33 | Button, Input, Card, Badge, Alert, etc., in 8 subcategories (form, data display, feedback, overlay, layout, primitives, content, marketing) |

| Layout Components | 2 | Header, Footer |
| Hero Components | 1 | Hero section |
| **Total** | **46** | From `component-registry.json` |

Projects also include supporting components that aren't in the registry: `SiteHeader` and `SiteFooter` in `src/components/site/`, plus layout, SEO, blog and landing components. See [Components Overview](/components/#also-in-your-project).
