| `src/lib/og.ts` | OG image generation |

## Pages and Views

Page content lives in `src/views/`. Files in `src/pages/` are thin wrappers that render a view with a locale, so the same view serves every language:

```astro
---
// src/pages/about.astro
import AboutView from '@/views/AboutView.astro';
import { defaultLocale } from '@/i18n';
---

<AboutView locale={defaultLocale} />
```

`src/pages/[lang]/` holds the wrappers for other languages. They generate nothing while your site has one language. See [Adding Routes](/customization/adding-routes/).

Pages are prerendered. Only Astro Actions, and any route you mark `export const prerender = false`, run on the server.

## Component Organization

Components are organized by category:

- **ui/** — 33 components organized into subcategories (form, data-display, feedback, overlay, layout, primitives, content, marketing)
- **patterns/** — 10 composed patterns (ContactForm, FormField, SearchInput, Section, PageHeader, MediaSlot, etc.)
- **layout/** — Page structure (Header, Footer, ThemeToggle, LanguageSwitcher, Analytics)
- **site/** — Your `SiteHeader` and `SiteFooter`. Every layout renders them, and upgrades leave them alone
- **seo/** — SEO utilities (meta tags, JSON-LD, inline scripts with CSP hashes)
- **blog/** — Blog-specific components
- **landing/** — Marketing page components
- **hero/** — Hero section

## Content Collections

Located in `src/content/`:

```
content/
├── blog/           # Blog posts (MDX)
│   ├── en/         # English posts
│   ├── es/         # Spanish posts
│   └── fr/         # French posts
├── pages/          # Static pages
├── authors/        # Author profiles (JSON)
└── faqs/           # FAQ entries (JSON)
```
