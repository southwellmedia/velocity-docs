Before starting with Velocity, ensure you have the following installed.

## Required

### Node.js 22.23.4 or higher

Velocity is built on Astro 7.4, which requires Node.js 22.23.4 or later. We recommend **Node 24 LTS**, which `.nvmrc` pins.

```bash
# Check your Node version
node --version

# Install with nvm
nvm install 24
nvm use 24
```

<Aside type="caution">
  Earlier Node 22 releases won't work. Check the Node version on your CI and hosting platform too.
</Aside>

### Package Manager

We recommend **pnpm 10**, which `package.json` pins and which matches the lockfile Velocity tests in CI:

```bash
# Install pnpm globally
npm install -g pnpm

# Verify installation
pnpm --version
```

npm, yarn and bun also work.

### Git

Required for cloning the repository and version control.

```bash
git --version
```

## Recommended

### VS Code Extensions

For the best development experience:

- **Astro** — Syntax highlighting and IntelliSense
- **Tailwind CSS IntelliSense** — Autocomplete for Tailwind classes
- **ESLint** — Code linting
- **Prettier** — Code formatting

### Browser DevTools

Modern browser with developer tools for debugging:

- Chrome DevTools
- Firefox Developer Tools
- Safari Web Inspector

## Verify Setup

Run these commands to verify your environment:

```bash
# Node.js (should be 22.23.4 or higher)
node --version

# Package manager
pnpm --version  # or npm --version

# Git
git --version
```

If all commands return version numbers, you're ready to [get started](/getting-started/).
