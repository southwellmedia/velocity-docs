`src/config/nav.config.ts` holds your routes, navigation and header and footer defaults. This file is yours, and upgrades don't overwrite it.

<Aside type="note">
  Astro still routes from the filesystem. This file only controls links and menus, so adding a route here doesn't create a page.
</Aside>

## Routes

`routes` lists each static page and its URL slug in each language:

```typescript
export interface RouteDefinition {
  /** URL path for the default locale, without slashes ('' = home). */
  path: string;
  /** Translated slugs for other locales. Falls back to `path`. */
  slugs?: Partial<Record<string, string>>;
  /** Set false for pages that only exist in the default locale. */
  localized?: boolean;
}

export const routes = {
  home: { path: '' },
  blog: { path: 'blog' },
  about: { path: 'about', slugs: { es: 'sobre-nosotros', fr: 'a-propos' } },
  contact: { path: 'contact', slugs: { es: 'contacto' } },
  search: { path: 'search', slugs: { es: 'buscar', fr: 'recherche' } },
  components: { path: 'components', localized: false },
} satisfies Record<string, RouteDefinition>;
```

Minimal projects start with `home`, `blog` and `search`.

## Navigation Items

`navItems` controls what appears in the header and footer:

```typescript
export const navItems: NavItem[] = [
  { label: 'nav.blog', route: 'blog', order: 1 },
  { label: 'nav.about', route: 'about', order: 2 },
  { label: 'Pricing', href: '/#pricing', order: 3 },
];
```

| Field | Description |
|-------|-------------|
| `label` | A translation key or plain text |
| `order` | Sort order, lowest first |
| `route` | An internal route ID, localized automatically |
| `href` | Any other link: an absolute path, a `#hash` or an external URL |
| `external` | Marks the link as external |

## Header Defaults

`headerConfig` sets the defaults for `<Header />`. Props passed to `Header` still win.

```typescript
export const headerConfig = {
  cta: { label: 'nav.docs', href: 'https://docs.deployvelocity.com' },
  actions: [
    {
      icon: 'github',
      href: 'https://github.com/your/repo',
      label: 'nav.github',
      iconOnly: true,
      target: '_blank',
    },
  ],
  extraNav: [{ label: 'nav.features', href: '/#features', order: 0 }],
};
```

## Footer Defaults

```typescript
export const footerConfig = {
  extraLinks: [
    { label: 'GitHub', href: 'https://github.com/your/repo', external: true, order: 100 },
  ],
};
```

## Link Helpers

Build internal links with the i18n helpers, which also work on single-language sites:

```astro
---
import { getLocale, localizeRoute, localizePath } from '@/i18n';
import { getNavItems } from '@/config/nav.config';

const locale = getLocale(Astro);
const navItems = getNavItems();
---

<a href={localizeRoute('about', locale)}>About</a>
<a href={localizePath('/blog/my-post', locale)}>A post</a>
```

`localizeRoute` throws if the route ID is unknown. The `RouteId` type catches that at compile time.

## Custom Navigation

The `Header` reads `navItems` automatically. To override it for one page:

```astro
<Header nav={[
  { label: 'Home', href: '/' },
  { label: 'Custom', href: '/custom' },
]} />
```
