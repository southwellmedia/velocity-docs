Deploy your Velocity site to Netlify. The Netlify adapter ships with Velocity and is selected automatically.

## Quick Deploy

<Steps>
1. Push your code to GitHub, GitLab, or Bitbucket

2. Log in to [Netlify](https://app.netlify.com)

3. Click "New site from Git"

4. Select your repository

5. Set environment variables

6. Click Deploy
</Steps>

## CLI Deployment

```bash
# Install Netlify CLI
pnpm add -g netlify-cli

# Login
netlify login

# Deploy preview
netlify deploy

# Deploy to production
netlify deploy --prod
```

## How It Works

Velocity detects Netlify from the `NETLIFY` environment variable and uses `@astrojs/netlify`. Pages are served as static files, and only Astro Actions and routes you mark `prerender = false` run as functions.

Route caching uses the Netlify CDN provider. See [Route Caching](/deployment/#route-caching).

## Configuration

`netlify.toml` ships with Velocity, along with security and cache headers:

```toml
[build]
  command = "pnpm run build"
  publish = "dist"

[build.environment]
  NODE_VERSION = "24"
```

## Environment Variables

Set in Netlify Dashboard → Site Settings → Environment Variables:

```bash
SITE_URL=https://your-site.netlify.app
PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
```

Or in `netlify.toml`:

```toml
[context.production.environment]
  SITE_URL = "https://yoursite.com"
```

| Setting | Value |
|---------|-------|
| Build Command | `pnpm run build` |
| Publish Directory | `dist` |
| Node Version | 24 |

## Deploy Previews

Every pull request gets a preview URL:

- `deploy-preview-123--your-site.netlify.app`

## Troubleshooting

### Node Version

Astro 7.4 needs Node 22.23.4 or later. Keep `NODE_VERSION` at `24` in `netlify.toml`.

### Forms Don't Submit

Check that the build log shows the Netlify adapter. If you set `DEPLOY_TARGET`, it overrides detection.
