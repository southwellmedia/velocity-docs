Vercel is the recommended platform for Velocity. The Vercel adapter ships with Velocity and is selected automatically, so there's nothing to configure.

## Quick Deploy

<Steps>
1. Push your code to GitHub, GitLab, or Bitbucket

2. Import project in [Vercel Dashboard](https://vercel.com/new)

3. Set environment variables:
   - `SITE_URL` = Your production domain

4. Click Deploy
</Steps>

## CLI Deployment

```bash
# Install Vercel CLI
pnpm add -g vercel

# Deploy
vercel

# Deploy to production
vercel --prod
```

## How It Works

Velocity detects Vercel from the `VERCEL` environment variable and uses `@astrojs/vercel`. Pages are served as static files, and only Astro Actions and routes you mark `prerender = false` run as functions.

Route caching uses the Vercel CDN provider, so `Astro.cache.set()` on an on-demand route writes real CDN headers and supports tag invalidation. See [Route Caching](/deployment/#route-caching).

`vercel.json` sets the build command and security headers.

## Environment Variables

Set in Vercel Dashboard → Project → Settings → Environment Variables:

```bash
SITE_URL=https://your-project.vercel.app
PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
```

<Aside type="tip">
  Environment variables are encrypted and only exposed during build/runtime.
</Aside>

## Custom Domain

1. Go to Project → Settings → Domains
2. Add your domain
3. Update DNS records as instructed
4. Update `SITE_URL` environment variable

## Build Settings

Vercel auto-detects Astro, and `vercel.json` sets the rest:

| Setting | Value |
|---------|-------|
| Framework Preset | Astro |
| Build Command | `pnpm run build` |
| Node.js Version | 24.x |

Leave the output directory unset. The adapter writes to `.vercel/output`.

## Preview Deployments

Every push creates a preview deployment:

- `https://your-project-git-branch-name.vercel.app`

Perfect for testing before merging to main.

## Troubleshooting

### Build Fails

Check build logs in Vercel Dashboard for errors. Make sure the project's Node.js version is 24.x.

### Environment Variables Not Working

- Ensure no typos in variable names
- Redeploy after adding/changing variables
- Check if variable should be `PUBLIC_` prefixed
- Declare new variables in `env.schema` in `astro.config.mjs`
