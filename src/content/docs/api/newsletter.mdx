The `newsletter` action handles submissions from the `NewsletterForm` component.

## Fields

| Field | Type | Required | Validation |
|-------|------|----------|------------|
| `email` | string | Yes | Valid email format |
| `website` | string | No | Hidden spam trap |

## Handler

The handler in `src/actions/index.ts` forwards the email address to `NEWSLETTER_ENDPOINT` when it's set, as JSON `{ "email": "..." }`. If `NEWSLETTER_API_KEY` is also set, it's sent as `Authorization: Bearer <key>`. With no endpoint, the signup is discarded and the server logs a warning. See [Delivering Submissions](/api/#delivering-submissions).

To call a provider's API directly instead, replace the forwarding and the `@velocity-stub` block, then delete the `@velocity-stub` line so `check:agent` stops warning:

```typescript
newsletter: defineAction({
  accept: 'form',
  input: newsletterSchema,
  handler: async ({ email, website }) => {
    if (website) return { success: true };

    await addSubscriber(email);
    return { success: true };
  },
}),
```

`NEWSLETTER_API_KEY` is already declared in the env schema as a server secret:

```typescript
import { NEWSLETTER_API_KEY } from 'astro:env/server';
```

## Integration Examples

To report a failure to the visitor, throw an `ActionError` from `astro:actions`. The form shows its generic error message.

### Mailchimp

```typescript
import { ActionError } from 'astro:actions';

async function addSubscriber(email: string) {
  const response = await fetch(
    `https://${DC}.api.mailchimp.com/3.0/lists/${LIST_ID}/members`,
    {
      method: 'POST',
      headers: {
        Authorization: `apikey ${NEWSLETTER_API_KEY}`,
        'Content-Type': 'application/json',
      },
      body: JSON.stringify({
        email_address: email,
        status: 'subscribed',
      }),
    }
  );

  if (!response.ok) {
    throw new ActionError({ code: 'INTERNAL_SERVER_ERROR', message: 'Failed to subscribe' });
  }
}
```

### ConvertKit

```typescript
async function addSubscriber(email: string) {
  const response = await fetch(
    `https://api.convertkit.com/v3/forms/${FORM_ID}/subscribe`,
    {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        api_key: NEWSLETTER_API_KEY,
        email,
      }),
    }
  );

  if (!response.ok) {
    throw new ActionError({ code: 'INTERNAL_SERVER_ERROR', message: 'Failed to subscribe' });
  }
}
```

### Resend

```typescript
import { Resend } from 'resend';

const resend = new Resend(NEWSLETTER_API_KEY);

async function addSubscriber(email: string) {
  await resend.contacts.create({
    email,
    audienceId: AUDIENCE_ID,
  });
}
```

## Client-Side Handling

`NewsletterForm` handles loading, success and error states for you, in the visitor's language. To call the action from your own form:

```typescript
import { actions, isInputError } from 'astro:actions';

form.addEventListener('submit', async (e) => {
  e.preventDefault();

  const { error } = await actions.newsletter(new FormData(form));

  if (!error) {
    form.innerHTML = '<p>Thanks for subscribing!</p>';
  } else if (isInputError(error)) {
    showError(error.fields.email?.[0]);
  } else {
    showError('Something went wrong. Please try again.');
  }
});
```
