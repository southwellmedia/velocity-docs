Velocity automatically generates OG images for all pages using [Satori](https://github.com/vercel/satori).

## How It Works

OG images are generated at build time by `src/pages/og/[...slug].png.ts`, for every route in `nav.config.ts` and every blog post, in every language.

### URL Patterns

| Page | OG Image URL |
|------|--------------|
| Homepage | `/og/index.png` |
| About | `/og/about.png` |
| Blog post | `/og/blog/my-post.png` |
| Spanish homepage | `/og/es/index.png` |
| Spanish about page | `/og/es/sobre-nosotros.png` |

## Automatic Integration

The `SEO` component points `og:image` at the matching file:

```astro
<!-- You don't need to specify this -->
<meta property="og:image" content="https://yoursite.com/og/about.png" />
```

The route and `SEO.astro` must stay in sync, so change them together. Velocity's E2E suite fetches every page's `og:image`.

Pages that aren't in `routes` have no generated image. Add them to `routes`, or pass an image yourself.

## Custom OG Images

Pass `image` to a layout:

```astro
<PageLayout
  title="Special Page"
  image="/custom-og-image.png"
>
  <!-- Content -->
</PageLayout>
```

A blog post with a cover `image` uses it as the social preview.

## Template Customization

The template is in `generateOGImage()` in `src/lib/og.ts`. It builds markup with `satori-html`, renders an SVG with Satori, and converts it to PNG with Sharp:

```typescript
export async function generateOGImage(options: OGImageOptions): Promise<Buffer> {
  const { title, description, type = 'website' } = options;

  const markup = html`
    <div style="height: 100%; width: 100%; display: flex; box-sizing: border-box;">
      <div style="display: flex; font-size: 64px;">${title}</div>
    </div>
  `;

  // Satori → SVG → Sharp → PNG
}
```

Every `div` needs an explicit `display` property for Satori.

<Aside type="note">
  Satori 0.63 and later handle padding differently, so any element with padding and a set width needs `box-sizing: border-box`, or its content can be clipped.
</Aside>

<Aside type="caution">
  OG images are generated at build time. Changes require a rebuild.
</Aside>

## Troubleshooting

### Images Not Generating

1. Check that the page is in `routes` in `nav.config.ts`
2. Check the build logs for errors

### Font Issues

Satori needs TTF or OTF, not WOFF2. Velocity bundles `public/fonts/inter-latin-400-normal.ttf`, so the build needs no network access. To use another font, add its file there and update `loadFont()` in `src/lib/og.ts`.

### Slow Builds

OG generation can be slow for large sites. Consider:

- Using simpler templates
- Reducing the number of fonts
