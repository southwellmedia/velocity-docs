Solutions for common issues in Velocity.

## Installation Issues

### "Cannot find module" errors

Clear and reinstall dependencies:

```bash
rm -rf node_modules pnpm-lock.yaml
pnpm install
```

### Node version errors

Astro 7.4 requires Node.js 22.23.4 or later. Node 24 LTS is recommended:

```bash
node --version  # Should be 22.23.4 or higher

# Using nvm
nvm install 24
nvm use 24
```

## Build Issues

### Tailwind classes not applying

1. Check that `global.css` is imported in your layout
2. Ensure the file is in Tailwind's content paths
3. For scoped styles, use `@reference`:

```astro
<style>
  @reference "../../styles/global.css";
  h1 { @apply text-2xl; }
</style>
```

### `FontFamilyNotFound`

A `<Font />` tag references a family that isn't in `fonts` in `astro.config.mjs`. See [Fonts](/customization/fonts/).

### Compiler errors about tags

Astro 7's Rust compiler fails on unclosed tags, and no longer fixes invalid nesting such as a `<div>` inside a `<p>`. Fix the markup it reports.

### Words run together

If inline elements lose the space between them, check that `compressHTML: true` is still set in `astro.config.mjs`. Astro 7's default of `'jsx'` removes that whitespace.

### Content collection type errors

Regenerate types:

```bash
pnpm astro sync
```

<Aside type="tip">Run this after adding or modifying collection schemas.</Aside>

### OG images not generating

1. Check that the page is in `routes` in `nav.config.ts`
2. Check build logs for errors

```bash
pnpm build 2>&1 | grep -i error
```

## Development Issues

### Hot reload not working

Try restarting the dev server:

```bash
# Stop with Ctrl+C
pnpm dev
```

### TypeScript errors

Update types:

```bash
pnpm astro sync
pnpm check
```

### Import alias not resolving

Check `tsconfig.json`:

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

### Scripts don't run

Velocity has no client router, so `astro:page-load` doesn't fire on first load. Call your init function directly. See [the upgrade guide](/upgrade-guides/v1-to-v2/#step-5-remove-clientrouter-dependencies).

### Search returns nothing

The index is only built by `pnpm build`, so test search with `pnpm preview`. Only content inside `data-pagefind-body` is indexed. See [Site Search](/configuration/search/).

### Scripts blocked by CSP

CSP only applies to production builds. If a script works in `pnpm dev` but not `pnpm preview`, see [Security & CSP](/configuration/security/).

## Component Issues

### Styles not scoped

Use `<style>` without `is:global`:

```astro
<style>
  /* These styles are scoped */
  .my-class { color: red; }
</style>
```

### Client-side interactivity not working

Add a client directive:

```astro
<Counter client:visible />
<Modal client:load />
```

### Images not loading

Use absolute paths from `public/` or import:

```astro
---
import myImage from '@/assets/image.png';
---

<img src={myImage.src} alt="Description" />
```

## Deployment Issues

### Forms don't submit

Forms need a server runtime. Check that the build used the right [adapter](/deployment/), and that your host isn't static-only.

### Environment variables not working

1. Ensure variables are set in hosting dashboard
2. Redeploy after adding variables
3. Check `PUBLIC_` prefix for client-side variables
4. Check that new variables are declared in `env.schema` in `astro.config.mjs`

### Build fails on hosting

Check that your hosting provider supports Node.js 22.23.4 or later.

Set in your hosting configuration:

```
NODE_VERSION=24
```

### 404 on routes

For static hosting, ensure `trailingSlash` is configured:

```javascript
// astro.config.mjs
export default defineConfig({
  trailingSlash: "always", // or 'never'
});
```
