Add new pages to your Velocity site. The CLI can do this when you create a project with `--pages`. To add one later, follow the steps here.

## Adding a Page

<Steps>
1. **Add the route and nav item** in `src/config/nav.config.ts`:

   ```typescript
   export const routes = {
     // ...existing routes
     pricing: { path: 'pricing' },
   };

   export const navItems: NavItem[] = [
     // ...existing items
     { label: 'pricing.title', route: 'pricing', order: 6 },
   ];
   ```

2. **Add the copy** in `src/i18n/translations/en.ts`:

   ```typescript
   const en = {
     // ...
     pricing: {
       title: 'Pricing',
       description: 'View our pricing plans',
     },
   };
   ```

   On a multi-language site, add the same keys to each file in `src/i18n/translations/`.

3. **Create the view** at `src/views/PricingView.astro`:

   ```astro
   ---
   import PageLayout from '@/layouts/PageLayout.astro';
   import { useTranslations, type Locale } from '@/i18n';

   interface Props {
     locale: Locale;
   }

   const { locale } = Astro.props;
   const t = useTranslations(locale);
   ---

   <PageLayout title={t('pricing.title')} description={t('pricing.description')}>
     <section class="mx-auto max-w-4xl px-6 py-24">
       <h1 class="text-4xl font-bold">{t('pricing.title')}</h1>
     </section>
   </PageLayout>
   ```

4. **Create the page wrapper** at `src/pages/pricing.astro`:

   ```astro
   ---
   import PricingView from '@/views/PricingView.astro';
   import { defaultLocale } from '@/i18n';
   ---

   <PricingView locale={defaultLocale} />
   ```

5. **Create the language wrapper** at `src/pages/[lang]/[...pricing].astro`:

   ```astro
   ---
   import PricingView from '@/views/PricingView.astro';
   import { getLocalizedStaticPaths, type Locale } from '@/i18n';

   export function getStaticPaths() {
     return getLocalizedStaticPaths('pricing', 'pricing');
   }

   const { locale } = Astro.props as { locale: Locale };
   ---

   <PricingView locale={locale} />
   ```

   It generates nothing while your site has one language, so it's safe to add now.
</Steps>

<Aside type="tip" title="Single-language site?">
  You can skip the wrappers and write a normal page in `src/pages/`. Add a view and wrappers when you need more languages.
</Aside>

## Hide a Page from Navigation

Add the route but leave it out of `navItems`:

```typescript
export const routes = {
  // ...
  privacy: { path: 'privacy' },
};
```

## Navigation Order

Lower numbers appear first:

```typescript
export const navItems: NavItem[] = [
  { label: 'nav.about', route: 'about', order: 1 },
  { label: 'nav.blog', route: 'blog', order: 2 },
  { label: 'pricing.title', route: 'pricing', order: 3 },
];
```

## Testing a New Page

The E2E suite reads pages from `routes`, so new routes are tested automatically: each must return 200, have no console errors or CSP violations, have one `<main>`, and pass axe accessibility checks.

## Dynamic Routes

Blog URLs come from `src/lib/blog.ts`. For your own collections, use `getStaticPaths()`:

```astro
---
// src/pages/projects/[slug].astro
import { getCollection, render } from 'astro:content';
import PageLayout from '@/layouts/PageLayout.astro';

export async function getStaticPaths() {
  const projects = await getCollection('projects');
  return projects.map((project) => ({
    params: { slug: project.id },
    props: { project },
  }));
}

const { project } = Astro.props;
const { Content } = await render(project);
---

<PageLayout title={project.data.title}>
  <Content />
</PageLayout>
```

## Nested Routes

Create folders for nested paths:

```
src/pages/
├── docs/
│   ├── index.astro            # /docs
│   ├── getting-started.astro  # /docs/getting-started
│   └── components/
│       └── button.astro       # /docs/components/button
```

## On-Demand Routes

Pages are prerendered. To render one on the server, opt out:

```astro
---
export const prerender = false;
---
```

Don't set `output: 'server'`. For form handling, use [Astro Actions](/api/).

## Linking to Routes

```astro
---
import { getLocale, localizeRoute } from '@/i18n';

const locale = getLocale(Astro);
---

<a href={localizeRoute('pricing', locale)}>View Pricing</a>
```
