## Common Changes

### Update Branding

1. Replace logos in `src/assets/branding/`
2. Update `public/favicon.svg`
3. Edit `site.config.ts` for site name and info

### Change Colors

Edit `src/styles/tokens/primitives.css`:

```css
:root {
  --brand-500: oklch(62.5% 0.22 260); /* Blue instead of orange */
}
```

### Switch Theme

Edit `src/styles/theme.css`:

```css
/* Default theme */
@import './themes/default.css';

/* Or use midnight theme */
@import './themes/midnight.css';
```

To make the site light or dark by default instead of following the visitor's system setting, set `defaultTheme` in `src/config/site.config.ts`. See [Dark Mode](/design-system/dark-mode/#default-theme).

### Add Navigation

Update `src/config/nav.config.ts`:

```typescript
export const routes = {
  // ... existing
  pricing: { path: 'pricing' },
};

export const navItems: NavItem[] = [
  // ... existing
  { label: 'Pricing', route: 'pricing', order: 6 },
];
```

### Customize Components

Edit components in `src/components/` or create new ones following existing patterns.
