Velocity is free and open source. **Velocity Premium** adds complete, ready-to-ship sites built on it, for one
payment: [deployvelocity.com/premium](https://deployvelocity.com/premium).

## What you get

- **Every template, current and future.** Each one is a complete Velocity project for a kind of business: every
  page it needs, sample content, English and Spanish, light and dark. New templates are added to the same
  repository, at no extra cost.
- **The Premium Kit.** 29 shared components every template is built from, such as pricing and compare tables,
  multi-step forms, filter grids, a lightbox, testimonials and live opening hours. The whole kit ships inside
  every template, so you can use any of it in any site. See [The Premium Kit](/premium/premium-kit/).
- **Full source with a commercial license.** Use the templates on any number of sites, including sites you build
  for clients. You can't share or resell the templates themselves.
- **Updates.** Velocity upgrades with the usual [`upgrade` command](/cli/upgrade/), and kit updates with
  `pnpm kit:update`. See [Updates](/premium/updates/).

| License | MIT | Commercial, unlimited sites |

Premium doesn't change how Velocity works. Every template is a normal Velocity project on the same components and
token system, so everything in these docs applies to it.

<Aside type="caution" title="Demo photos aren't included">
The hosted demos use stock photos that aren't licensed for resale, so templates ship with labelled placeholders.
Each template's README lists the photo names it expects. Try every demo before you buy: all sales are final,
because you get the full source.
</Aside>
