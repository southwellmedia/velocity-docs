Pattern components combine multiple UI components into reusable patterns.

## ContactForm

Complete contact form, backed by the [`contact` action](/api/contact/):

```astro
---
import ContactForm from '@/components/patterns/ContactForm.astro';
---

<ContactForm successMessage="Thanks! We'll be in touch soon." />
```

### Features

- Name, email, subject, and message fields
- Server-side validation with translated messages
- Honeypot spam protection
- Success/error states
- Accessible form structure

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `action` | `string` | `actions.contact` | [Your own endpoint](/api/contact/#using-your-own-endpoint), instead of the action |
| `successMessage` | `string` | `t('form.sent')` | Success message |
| `submitLabel` | `string` | `t('form.submit')` | Submit button text |
| `labels` | `Partial<Record<Field, string>>` | — | Override field labels |
| `placeholders` | `Partial<Record<Field, string>>` | — | Override field placeholders |

Text defaults come from the built-in UI strings, in the visitor's language.

## NewsletterForm

Email subscription form, backed by the [`newsletter` action](/api/newsletter/):

```astro
---
import NewsletterForm from '@/components/patterns/NewsletterForm.astro';
---

<NewsletterForm
  placeholder="Enter your email"
  buttonText="Subscribe"
/>
```

### Features

- Single email field
- Inline button layout
- Loading state
- Success/error feedback

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `action` | `string` | `actions.newsletter` | Your own endpoint, instead of the action |
| `placeholder` | `string` | `t('form.emailPlaceholder')` | Input placeholder |
| `buttonText` | `string` | `t('form.subscribe')` | Button text |
| `successMessage` | `string` | `t('form.subscribed')` | Success message |

## FormField

Wrapper for consistent form field layouts:

```astro
---
import FormField from '@/components/patterns/FormField.astro';
---

<FormField
  label="Email"
  name="email"
  type="email"
  required
  hint="We'll never share your email"
/>
```

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | — | Field label |
| `name` | `string` | — | Input name |
| `type` | `string` | `'text'` | Input type |
| `required` | `boolean` | `false` | Required field |
| `hint` | `string` | — | Helper text |
| `error` | `string` | — | Error message |
