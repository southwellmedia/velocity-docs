Velocity includes 70 components, listed in its component registry (`component-registry.json`). `.agents/components.md` describes all of them for [AI coding agents](/getting-started/ai-agents/), and the [CLI](/cli/components/) lets you choose which UI, pattern and hero components a new project includes.

## Component Philosophy

1. **Astro-first** — Components work without client JavaScript
2. **Composable** — Small, single-purpose primitives
3. **Accessible** — WCAG 2.2 AA compliant
4. **Token-based** — No hardcoded colors/sizes
5. **Variant-rich** — Multiple visual options per component

## Import Patterns

### Direct Import

```astro
---
import { Button, Card } from '@/components/ui';
---

<Button>Click me</Button>
<Card>Content</Card>
```

The `@/components/ui` barrel exists when you install all components. After a partial install, import from the component's folder, such as `@/components/ui/form/Button/Button.astro`.

### Path Alias

All components use the `@/` alias pointing to `src/`:

```typescript
// tsconfig.json
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

## Common Patterns

### Variants and Sizes

Most components accept `variant` and `size` props:

```astro
<Button variant="primary" size="lg">Large Primary</Button>
<Button variant="outline" size="sm">Small Outline</Button>
```

### Dark Sections

For components on a dark background, wrap them in `.invert-section`, which flips the tokens inside it:

```astro
<div class="invert-section bg-background">
  <Button>On Dark Background</Button>
</div>
```
