Quick reference for additional UI components.

## Form Components

### Textarea

Multi-line text input:

```astro
<Textarea
  label="Message"
  name="message"
  hint="Enter your message"
  rows={5}
/>
```

- Since 2.7, Textarea grows with what you type (CSS `field-sizing: content`, where supported), up to 60% of the viewport height. `rows` still sets the starting height. Pass `autoResize={false}` for a fixed height.
- Like Input and Select, it shows a message after a visitor leaves it invalid (`required`, `minlength`, `maxlength`). See [Errors after interaction](/components/ui/input/#errors-after-interaction).

### Select

Dropdown select menu:

```astro
<Select
  label="Country"
  name="country"
  options={[
    { value: 'us', label: 'United States' },
    { value: 'uk', label: 'United Kingdom' },
    { value: 'ca', label: 'Canada' },
  ]}
/>
```

- With `required`, Select shows a message after the visitor leaves it without a choice. See [Errors after interaction](/components/ui/input/#errors-after-interaction).

### Checkbox

```astro
<Checkbox
  label="I agree to the terms"
  name="terms"
  required
/>
```

### Radio

```astro
<Radio
  label="Option A"
  name="choice"
  value="a"
/>
<Radio
  label="Option B"
  name="choice"
  value="b"
/>
```

### ToggleGroup

A segmented control (one choice from a few, e.g. Monthly / Yearly) built from native radio inputs: works without JavaScript and submits with a form.

```astro
---
import ToggleGroup from '@/components/ui/form/ToggleGroup/ToggleGroup.astro';
---

<ToggleGroup
  name="billing"
  label="Billing period"
  value="monthly"
  options={[{ value: 'monthly', label: 'Monthly' }, { value: 'yearly', label: 'Yearly' }]}
/>
```

- Use ToggleGroup for a short set of mutually exclusive options instead of hand-built segmented buttons; use Tabs when each option shows different content.

## Display Components

### Avatar

User profile image. Extends `HTMLAttributes<'div'>`.

```astro
<Avatar
  src="/avatars/user.jpg"
  alt="John Doe"
  size="lg"
  fallback="JD"
/>
```

### Skeleton

Loading placeholder. Extends `HTMLAttributes<'div'>`.

```astro
<Skeleton variant="text" width="100%" />
<Skeleton variant="circular" width="40px" height="40px" />
<Skeleton variant="default" height="200px" />
```

### Icon

Any [Lucide](https://lucide.dev/icons) icon by its kebab-case name, aliases included, drawn as an inline SVG at build time (no JavaScript). Sizes are presets: `xs`, `sm`, `md` (default), `lg`, `xl`. A few brand marks Lucide doesn't ship (`github`, `twitter`, `linkedin` and the `brand-*` logos) are built in. An unknown name draws an `x` and warns during the build.

```astro
<Icon name="search" size="sm" />
<Icon name="calendar-check" size="lg" strokeWidth={1.5} />
```

In a React island that needs the icon in its first paint, import it from `lucide-react` by name instead.

### Carousel

A sideways-scrolling row of slides on CSS scroll snap (swipe, trackpad, keyboard); 1-4 slides in view. Since 2.7:

- Previous and next move one slide at a time to the next snap point, and stop at the ends.
- A marker button per position jumps straight to it. The current marker is wider, so it doesn't rely on colour alone.
- Each slide is a group named "2 of 4", and a hidden status line announces "Slide 2 of 4" once scrolling settles. "Carousel" and "slide" are translated.
- A slide that is a link, button or image, or already has its own role or label, is wrapped instead of renamed, so it keeps its name.
- With `hideControls`, a thin scrollbar stays visible as the cue that the row scrolls.

```astro
---
import Carousel from '@/components/ui/data-display/Carousel/Carousel.astro';
import Card from '@/components/ui/data-display/Card/Card.astro';
---

<Carousel label="Customer stories" perView={3}>
  <Card>One</Card>
  <Card>Two</Card>
  <Card>Three</Card>
  <Card>Four</Card>
</Carousel>
```

- Use Carousel for galleries and card rows that scroll sideways instead of a hand-built slider script.

### Kbd

A keyboard key, or a combination such as ⌘ K from a keys array.

```astro
---
import Kbd from '@/components/ui/content/Kbd/Kbd.astro';
---

Press <Kbd keys={['⌘', 'K']} /> to search, or <Kbd>Esc</Kbd> to close.
```

- Use Kbd for keys and shortcuts in docs and UI hints instead of styled `<code>`.

### Spinner

A loading spinner that inherits the text colour, with a screen-reader label; stops with reduced motion.

```astro
---
import Spinner from '@/components/ui/feedback/Spinner/Spinner.astro';
---

<Spinner size="sm" label="Loading results" />
```

- Use Spinner for a loading state outside a button; Button has its own loading prop.

## Interactive Components

### Dialog

A modal on the native `<dialog>` element, opened with `showModal()` (2.7+). The browser contains focus, makes the rest of the page inert, closes it on Escape and the back gesture, and returns focus to the button that opened it. The page doesn't shift sideways when it opens, and the dialog animates in and out.

```astro
---
import Dialog from '@/components/ui/overlay/Dialog/Dialog.astro';
import Button from '@/components/ui/form/Button/Button.astro';
---

<Button variant="destructive" data-dialog-open="delete-dialog">Delete project</Button>

<Dialog id="delete-dialog" title="Delete project?" description="This can't be undone." size="sm">
  <p class="text-sm text-foreground-muted">All deployments will be removed.</p>
  <div slot="footer" class="flex justify-end gap-3 px-6 pb-6">
    <Button variant="outline" data-dialog-close>Cancel</Button>
    <Button variant="destructive" data-dialog-close>Delete</Button>
  </div>
</Dialog>
```

- **Open:** any button with `data-dialog-open="<id>"` (no script needed), `window.openDialog(id)`, or the element's own `showModal()`.
- **Close:** buttons with `data-dialog-close` (inside the dialog, or `data-dialog-close="<id>"` anywhere), Escape, a click on the backdrop, `window.closeDialog(id)`, or `close()`. Listen for the element's `close` event to react however it closed.
- **Props:** `id`, `title`, `description`, `label` (accessible name when there's no title), `size` (`sm`, `md`, `lg`, `xl`) and `closedby`: `'any'` (Escape and backdrop click, the default), `'closerequest'` (Escape only) or `'none'` (only your code closes it). Safari doesn't support `closedby` yet; Velocity adds the backdrop click and the `'none'` behaviour there.
- **React island:** `import { Dialog } from '@/components/ui/overlay/Dialog/Dialog'`, with `open` and `onClose`, plus optional `label`, `closeLabel` and `closedby`.

<Aside type="caution" title="Upgrading from 2.6">
  `dialogElement.open()` no longer works: on a `<dialog>`, `open` is a built-in property. Call `window.openDialog(id)` or `showModal()` instead. `close()` still works.
</Aside>

### Dropdown

A menu of links opened from the button in its `trigger` slot. Since 2.7 the menu is a native `popover` in the browser's top layer, so a parent with `overflow: hidden` or a lower `z-index` can't clip it. Escape and outside clicks close it.

```astro
---
import Dropdown from '@/components/ui/overlay/Dropdown/Dropdown.astro';
import Button from '@/components/ui/form/Button/Button.astro';
---

<Dropdown
  align="end"
  items={[
    { label: 'Edit', href: '/settings', icon: 'edit' },
    { label: 'Duplicate', href: '/duplicate', icon: 'copy' },
    { label: '', separator: true },
    { label: 'Archive', href: '/archive', icon: 'archive', disabled: true },
  ]}
>
  <Button slot="trigger" variant="outline">Actions</Button>
</Dropdown>
```

- The trigger is announced as a menu button (`aria-haspopup="menu"`, `aria-expanded`). Arrow keys, Home and End move between items, and the menu is one Tab stop; Tab moves past it.
- Opening from the keyboard or a screen reader moves focus to the first item. A mouse or touch click leaves focus on the trigger, as native menus do, and ArrowDown enters the menu.
- It sits next to its button with CSS anchor positioning, flipping when there's no room, and falls back to a few lines of script in browsers without it.
- The trigger can be a `<button>` or a link-styled `Button`.

### Tooltip

Hover tooltip. Extends `HTMLAttributes<'span'>`.

```astro
<Tooltip content="This is helpful information">
  <Button>Hover me</Button>
</Tooltip>
```

### Tabs

Horizontal tabs:

```astro
<Tabs
  tabs={[
    { id: 'overview', label: 'Overview' },
    { id: 'features', label: 'Features' },
    { id: 'pricing', label: 'Pricing' },
  ]}
  defaultTab="overview"
>
  <div data-tab="overview">Overview content</div>
  <div data-tab="features">Features content</div>
  <div data-tab="pricing">Pricing content</div>
</Tabs>
```

### VerticalTabs

Vertical tab navigation (mobile dropdown):

```astro
<VerticalTabs
  tabs={[
    { id: 'account', label: 'Account' },
    { id: 'security', label: 'Security' },
    { id: 'billing', label: 'Billing' },
  ]}
  defaultTab="account"
/>
```

### Sheet

A panel that slides in and out from the left, right or bottom (filters, cart, menu), on the native `<dialog>`: focus stays inside, and Escape or a click on the backdrop closes it. Scrolling inside it doesn't scroll the page behind. Opened by any button with `data-sheet-open`; buttons with `data-sheet-close` close it.

```astro
---
import Sheet from '@/components/ui/overlay/Sheet/Sheet.astro';
import Button from '@/components/ui/form/Button/Button.astro';
---

<Button data-sheet-open="filters">Filters</Button>
<Sheet id="filters" title="Filters" side="right">
  <p>Filter controls go here.</p>
  <Button slot="footer" data-sheet-close fullWidth>Show results</Button>
</Sheet>
```

- Use Sheet for a side panel or bottom drawer; use Dialog for a centered modal.

### Popover

A small panel anchored to its button (details, a few actions), on the native popover attribute: Escape and outside clicks close it with no script. Since 2.7 it's placed with CSS anchor positioning (`placement="bottom" | "top"`, `align="start" | "end"`), flipping at the viewport edge, with a script fallback that keeps it on screen in browsers without anchor positioning.

```astro
---
import Popover from '@/components/ui/overlay/Popover/Popover.astro';
---

<Popover label="Plan details">
  <Fragment slot="trigger">Details</Fragment>
  <p>Billed yearly. Cancel any time.</p>
</Popover>
```

- Use Popover for interactive content next to a button; use Tooltip for a short read-only hint and Dropdown for a menu of actions.

```astro

  code={`const greeting = 'Hello, World!';`}

  filename="example.js"
/>
```

Testimonial card:

```astro
<SocialProof
  quote="This product changed our workflow completely."

  avatar="/avatars/jane.jpg"
/>
```

### NpmCopyButton

NPM install command copier:

```astro
<NpmCopyButton package="velocity" />
```

### TerminalDemo

Animated terminal demo (React component):

```astro
<TerminalDemo
  client:visible
  commands={['npm install velocity', 'npm run dev']}
  output={['Installing...', 'Server running at localhost:4321']}
/>
```

### VideoEmbed

A YouTube or Vimeo video that loads only on play: until then a poster and no third-party request or cookies (youtube-nocookie, Vimeo dnt).

```astro
---
import VideoEmbed from '@/components/ui/marketing/VideoEmbed/VideoEmbed.astro';
---

<VideoEmbed provider="youtube" videoId="dQw4w9WgXcQ" title="Product tour" />
```

- Use VideoEmbed for any YouTube or Vimeo video instead of a raw `<iframe>`, which loads third-party scripts and cookies on page load.

### AnnouncementBar

A strip above the header for a launch or notice: message, optional link and close button; a dismissed bar stays closed per id.

```astro
---
import AnnouncementBar from '@/components/ui/marketing/AnnouncementBar/AnnouncementBar.astro';
---

<AnnouncementBar id="launch-2-6" href="/blog/velocity-2-6" linkLabel="Read the post" tone="brand">
  Velocity 2.6 is out.
</AnnouncementBar>
```

- Use AnnouncementBar for site-wide notices instead of an Alert at the top of a page; change its id for each new announcement.
