UI components are the building blocks of your interface. They're designed to be composable, accessible, and customizable through props.

## Available Components

Components are organized into subcategories under `src/components/ui/`.

### Form (`ui/form/`)

| Component | Purpose |
|-----------|---------|
| `Button` | Clickable actions with multiple variants |
| `Input` | Text input with label, hint, and error states |
| `Textarea` | Multi-line text input |
| `Select` | Dropdown select menu |
| `Checkbox` | Checkbox input with label |
| `Radio` | Radio button for single selection |
| `Switch` | Toggle switch input |
| `ToggleGroup` | Segmented control built from native radio inputs |

### Data Display (`ui/data-display/`)

| Component | Purpose |
|-----------|---------|
| `Card` | Container with structured content |
| `Badge` | Status labels and tags |
| `Avatar` | User profile images |
| `AvatarGroup` | Grouped avatar display |
| `Table` | Data table with styling |
| `Pagination` | Page navigation controls |
| `Progress` | Progress bar indicator |
| `Skeleton` | Loading placeholders |
| `GoogleMap` | Consent-aware embedded map |
| `Carousel` | Sideways-scrolling row of slides on CSS scroll snap |

### Feedback (`ui/feedback/`)

| Component | Purpose |
|-----------|---------|
| `Alert` | Contextual feedback messages |
| `Toast` | Temporary notification messages |
| `Tooltip` | Hover tooltips |
| `Spinner` | Loading spinner with a screen-reader label |

### Overlay (`ui/overlay/`)

| Component | Purpose |
|-----------|---------|
| `Dialog` | Modal dialogs |
| `Dropdown` | Dropdown menus |
| `Tabs` | Horizontal tab navigation |
| `VerticalTabs` | Vertical tab navigation |
| `Accordion` | Collapsible content sections |
| `ConsentBanner` | Cookie consent banner |
| `Sheet` | Panel that slides in from the left, right or bottom |
| `Popover` | Small panel anchored to its button |

### Layout (`ui/layout/`)

## Common Props

Most UI components share these patterns:

### Variant

Visual style options:

```astro
<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="outline">Outline</Button>
<Button variant="ghost">Ghost</Button>
```

### Size

Size options (usually `sm`, `md`, `lg`):

```astro
<Button size="sm">Small</Button>
<Button size="md">Medium</Button>
<Button size="lg">Large</Button>
```

### Dark Sections

For dark backgrounds, wrap components in `.invert-section` instead of passing a prop:

```astro
<div class="invert-section bg-background">
  <Button>On Dark</Button>
</div>
```

## Import Example

```astro
---
import { Button, Input, Card } from '@/components/ui';
---

<Card>
  <Input label="Email" name="email" type="email" />
  <Button>Submit</Button>
</Card>
```

The `@/components/ui` barrel exists when you install all components. After a partial install, import from the component's folder, such as `@/components/ui/form/Button/Button.astro`.
