Layout components provide the structural elements for your pages.

## Available Components

| Component | Purpose |
|-----------|---------|
| `Header.astro` | Site header with navigation |
| `Footer.astro` | Site footer with links |
| `ThemeToggle.astro` | Dark mode toggle |
| `LanguageSwitcher.astro` | Language picker |
| `Analytics.astro` | Analytics integration |

Layouts don't render `Header` and `Footer` directly. They render `SiteHeader` and `SiteFooter` from `src/components/site/`, which wrap them with your site's defaults. Those two files are yours and upgrades leave them alone, so customize the header and footer there. Upgrades replace the files in `src/components/layout/`.

## Header

Full-featured header with navigation, actions, and mobile menu:

```astro
<Header
  showCta
  cta={{ label: 'Get Started', href: '/signup' }}
  showThemeToggle
/>
```

[View Header documentation →](/components/layout/header)

## Footer

Flexible footer with multiple layouts:

```astro
<Footer layout="columns" columns={3} />
```

[View Footer documentation →](/components/layout/footer)

## ThemeToggle

Dark mode toggle component:

```astro
<ThemeToggle />
```

## LanguageSwitcher

Links to the current page in each language, or to that language's home page if the page has no translation. It's a native `<details>` element, so it needs no JavaScript.

`Header` renders it automatically when more than one language is enabled:

```astro
<LanguageSwitcher />
<LanguageSwitcher variant="list" />
```

## Analytics

Conditionally loads analytics scripts:

```astro
<!-- Automatically included in BaseLayout if configured -->
<Analytics />
```
