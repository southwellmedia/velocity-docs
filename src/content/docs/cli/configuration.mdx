After scaffolding, make the project yours.

## Environment Variables

```bash
cp .env.example .env
```

```bash
# Your production URL
SITE_URL=https://your-domain.com

# Analytics (optional)
PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
PUBLIC_GTM_ID=GTM-XXXXXXX

# Site verification (optional)
GOOGLE_SITE_VERIFICATION=your-verification-code
BING_SITE_VERIFICATION=your-verification-code
```

See [Environment Variables](/configuration/environment/) for the full list.

## Site Details

Edit `src/config/site.config.ts` with your name, description, contact details, social links and theme color. See [Site Configuration](/configuration/site-config/).

## Navigation

`src/config/nav.config.ts` holds your routes, menu items, header button and footer links. See [Routes & Navigation](/configuration/routes/).

## Branding Files

<Steps>
1. **Favicon**

   Replace `public/favicon.svg`.

2. **Logos**

   Replace the files in `src/assets/branding/`:
   - `logomark.svg` — Icon for light backgrounds
   - `logomark-dark.svg` — Icon for dark backgrounds
   - `logo-full.svg` — Full logo for light backgrounds
   - `logo-full-dark.svg` — Full logo for dark backgrounds

3. **Theme color**

   Update `themeColor` in `site.config.ts`.
</Steps>

## Forms

The contact and newsletter forms validate input, then forward each submission to `CONTACT_FORM_ENDPOINT` or `NEWSLETTER_ENDPOINT` when you set them. Until you set an endpoint or connect a provider in `src/actions/index.ts`, submissions are discarded. See [Forms & Actions](/api/#delivering-submissions).

## Development Commands

```bash
pnpm dev        # Start the dev server at localhost:4321
pnpm build      # Build for production
pnpm preview    # Preview the production build
pnpm validate   # Lint, type check, unit tests, build and agent-ready check
```

See [Scripts](/getting-started/scripts/) for the rest.

## Deployment

The adapter is picked automatically on Vercel, Netlify and Cloudflare, and defaults to a Node server everywhere else. See [Deployment](/deployment/).

<Aside type="tip">
  Keep `.velocity.json` in your repository. The `upgrade` command needs it.
</Aside>
