The CLI can remove the optional components you don't need. Optional components live in `src/components/ui`, `src/components/patterns` and `src/components/hero`.

Every project gets all components unless you pass `--components`. The wizard doesn't ask.

| Flag | What's kept |
|------|-------------|
| `--components` (or no flag) | Every component |
| `--components=ui,patterns` | The categories you choose, plus their dependencies |
| `--components=none` | Only the components core pages need |

<Aside type="tip">
  Keep all of them if you're unsure. Astro only ships the components you use, so unused ones don't add to your pages, and your AI agent can use any of them.
</Aside>

<Aside type="note" title="Demo projects keep everything">
  The demo pages use every component, so `--start demo` ignores your selection and keeps all of them.
</Aside>

## Examples

<Tabs>
  <TabItem label="All">
    ```bash
    pnpm create velocity-astro my-site --components
    ```
  </TabItem>
  <TabItem label="None">
    ```bash
    pnpm create velocity-astro my-site --components=none
    ```
  </TabItem>
  <TabItem label="Categories">
    ```bash
    pnpm create velocity-astro my-site --components=ui
    pnpm create velocity-astro my-site --components=ui,patterns
    ```
  </TabItem>
</Tabs>

The categories are `ui`, `patterns` and `hero`.

## Always Included

These registry components stay whatever you choose, because the core pages and layouts import them:

- `Badge`, `Button`, `ConsentBanner`, `CTA`, `Hero`, `Icon`, `Logo`, `MediaSlot`, `NewsletterForm`, `PageHeader`, `SearchInput` and `Section`
- Anything those components depend on

Everything outside the optional folders also stays, including layouts, `src/components/layout`, `src/components/seo`, `src/components/blog`, `src/i18n` and `src/lib`.

The list comes from `scaffold.components.alwaysInclude` in `velocity-manifest.json`, so it can change between Velocity releases.

<Aside type="caution" title="Importing from barrels">
  Partial installs remove the barrel files `src/components/ui/index.ts` and `src/components/ui/<category>/index.ts`. Import from the component's folder instead:

  ```astro
  ---
  import Button from '@/components/ui/form/Button/Button.astro';
  ---
  ```
</Aside>

## Dependency Resolution

Selecting a component also keeps the components it imports. `component-registry.json` in Velocity lists each component's files and dependencies, and Velocity's CI fails if a file is unregistered or a dependency is undeclared.
