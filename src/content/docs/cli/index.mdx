`create-velocity-astro` creates and upgrades [Velocity](https://github.com/southwellmedia/velocity) projects. Version 2 ships no template files: it downloads Velocity and applies the recipe in Velocity's own manifest, so what you get is what Velocity tests in CI.

<Aside type="note" title="Requirements">
  The CLI runs on Node.js 20.19 or later and needs Velocity 2.0 or later. Generated projects need **Node.js 22.23.4 or later** (Node 24 LTS recommended).
</Aside>

## Quick Start

<Tabs>
  <TabItem label="pnpm" icon="pnpm">

    ```bash
    pnpm create velocity-astro my-site
    ```
  </TabItem>
  <TabItem label="npm" icon="seti:npm">

## Interactive Wizard

Run the command and answer the prompts:

```
◇  What is your project name?
│  rosas-bakery
│
◇  What are you starting?
│  ● My own site       A clean project your AI agent builds into your site
│  ○ Explore the Velocity demo
│  ○ Blank project
│
◇  Site name?
│  Rosa's Bakery
│
◇  What's the site for? One sentence, or Enter to skip
│  A neighbourhood bakery in Leith with a wood-fired oven
│
◇  Add internationalization (i18n)?
│  No
│
◇  Which package manager?
│  pnpm
```

<Steps>
1. **Project name**

   The folder to create. It's normalized to a valid package name.

2. **What you're starting**

   - **My own site:** a minimal project (home page, blog and search) set up for your AI agent to build into your site. The CLI writes your answers to a site brief, `.agents/site.md`.
   - **Explore the Velocity demo:** the demo landing page, About, Contact and component showcase pages, and sample content.
   - **Blank project:** the same minimal project, without the brief, for building by hand.

3. **Site name** (own site only)

   Written to `src/config/site.config.ts`, the README and the brief. Defaults to the project name, title-cased.

4. **What the site is for** (own site only)

   One sentence for the brief. Press Enter to skip, and your agent will ask.

5. **Internationalization**

   Enables Spanish and French alongside English. See [i18n](/cli/i18n/).

6. **Package manager**

   Preselected from the command you ran.
</Steps>

Components and starter pages aren't prompts: every project gets all components, and you can change that with [`--components`](/cli/components/) and [`--pages`](#starter-pages).

## Flags

Flags skip the matching prompt.

| Flag | Default | Description |
|------|---------|-------------|
| `--start own\|demo\|blank` | prompt | What you're starting. `own` if you skip prompts |
| `--demo` | | Same as `--start demo` |
| `--name "Rosa's Bakery"` | project name, title-cased | Site name (own site) |
| `--describe "…"` | | One sentence on what the site is for (own site) |
| `--components` | all | All components |
| `--components=none` | | Only what core pages need |
| `--components=ui,patterns,hero` | | Specific categories |
| `--i18n` | prompt | Enable English, Spanish and French |
| `--pages` | | Ask for starter page names |
| `--pages="Pricing, Team"` | | Generate these pages without asking |
| `--ref <tag\|branch>` | latest release | Velocity tag or branch to scaffold from |
| `--template <dir>` | | Scaffold from a local Velocity checkout |
| `--no-install` | | Skip installing dependencies |
| `-y, --yes` | | Skip all prompts |
| `-h, --help` | | Show help |
| `-v, --version` | | Show the CLI version |

`--ref` and `--template` can't be combined.

### Defaults with `--yes`

`-y` creates an **own site** project with all components, one language and **pnpm**, whichever command you used to start it. The site name defaults to the project name, title-cased. Add flags to change that:

```bash
# Own site with its brief seeded
pnpm create velocity-astro rosas-bakery -y --name "Rosa's Bakery" --describe "Neighbourhood bakery in Leith"

# Blank project, only the components core pages need
pnpm create velocity-astro my-site -y --start blank --components=none

# Minimal project, all components
pnpm create velocity-astro my-site -y

# Minimal project, only the components core pages need
pnpm create velocity-astro my-site -y --components=none

# Full demo in three languages
pnpm create velocity-astro my-site -y --demo --i18n

# Pin a Velocity version
pnpm create velocity-astro my-site -y --ref v2.0.0

# Scaffold without installing
pnpm create velocity-astro my-site -y --no-install
```

<Aside type="caution" title="Using npm?">
  npm keeps flags for itself unless you put them after `--`:

  ```bash
  npm create velocity-astro@latest my-site -- --demo --i18n
  ```
</Aside>

## Starter Pages

`--pages` creates pages that follow Velocity's structure. For `--pages="Pricing Plans"` the CLI adds:

| File | What it adds |
|------|--------------|
| `src/views/PricingPlansView.astro` | The page content |
| `src/pages/pricing-plans.astro` | Wrapper for the default language |
| `src/pages/[lang]/[...pricingPlans].astro` | Wrapper for other languages |
| `src/config/nav.config.ts` | A route and a nav item |
| `src/i18n/translations/*.ts` | Title and description strings, in every language file |

The names `index`, `blog`, `404`, `rss`, `search` and `lang` are reserved and skipped. Pages use `PageLayout`. On an own site, the pages are also listed in the brief's sitemap as planned.

## After Scaffolding

```bash
cd my-site
pnpm dev
```

Your site runs at `http://localhost:4321`.

For an own site, open the project in your AI coding agent and ask it to **"Set up this site"**. It reads the brief, asks what's missing, and builds your pages. See [Set up your site with an agent](/getting-started/ai-agents/#set-up-your-site). For the demo, ask it to **"Replace the demo with my site"** when you're ready.
