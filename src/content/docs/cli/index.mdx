`create-velocity-astro` creates and upgrades [Velocity](https://github.com/southwellmedia/velocity) projects. Version 2 ships no template files: it downloads Velocity and applies the recipe in Velocity's own manifest, so what you get is what Velocity tests in CI.

<Aside type="note" title="Requirements">
  The CLI runs on Node.js 20.19 or later and needs Velocity 2.0 or later. Generated projects need **Node.js 22.23.4 or later** (Node 24 LTS recommended).
</Aside>

## Interactive Wizard

Run the command and answer the prompts:

```
◇  What is your project name?
│  my-site
│
◇  Include demo landing page and sample content?
│  No
│
◇  Include optional components?
│  ● All
│  ○ Select categories
│  ○ Select individual
│  ○ None
│
◇  Add internationalization (i18n)?
│  No
│
◇  Generate starter pages?
│  No
│
◇  Which package manager?
│  pnpm
```

<Steps>
1. **Project name**

   The folder to create. It's normalized to a valid package name.

2. **Demo content**

   **No** gives a minimal starter with a home page, blog and search. **Yes** adds the demo landing page, About, Contact and component showcase pages, and sample content.

3. **Optional components**

   Keep all of them, pick categories, pick individual components, or keep only what the core pages need. See [Component Selection](/cli/components/).

4. **Internationalization**

   Enables Spanish and French alongside English. See [i18n](/cli/i18n/).

5. **Starter pages**

   Enter a comma-separated list of page names, such as `Pricing, Team, FAQ`. See [Starter Pages](#starter-pages).

6. **Package manager**

   Preselected from the command you ran.
</Steps>

## Flags

Flags skip the matching prompt.

| Flag | Default | Description |
|------|---------|-------------|
| `--demo` | prompt | Include the demo pages and sample content |
| `--components` | prompt | All components |
| `--components=none` | | Only what core pages need |
| `--components=ui,patterns,hero` | | Specific categories |
| `--i18n` | prompt | Enable English, Spanish and French |
| `--pages` | prompt | Ask for starter page names |
| `--pages="Pricing, Team"` | | Generate these pages without asking |
| `--ref <tag\|branch>` | latest release | Velocity tag or branch to scaffold from |
| `--template <dir>` | | Scaffold from a local Velocity checkout |
| `--no-install` | | Skip installing dependencies |
| `-y, --yes` | | Skip all prompts |
| `-h, --help` | | Show help |
| `-v, --version` | | Show the CLI version |

`--ref` and `--template` can't be combined.

### Defaults with `--yes`

`-y` creates a **minimal** project with all components, one language and **pnpm**, whichever command you used to start it. Add flags to change that:

```bash
# Minimal project, all components
pnpm create velocity-astro my-site -y

# Minimal project, only the components core pages need
pnpm create velocity-astro my-site -y --components=none

# Full demo in three languages
pnpm create velocity-astro my-site -y --demo --i18n

# Pin a Velocity version
pnpm create velocity-astro my-site -y --ref v2.0.0

# Scaffold without installing
pnpm create velocity-astro my-site -y --no-install
```

<Aside type="caution" title="Using npm?">
  npm keeps flags for itself unless you put them after `--`:

  ```bash
  npm create velocity-astro@latest my-site -- --demo --i18n
  ```
</Aside>

## Starter Pages

`--pages` creates pages that follow Velocity's structure. For `--pages="Pricing Plans"` the CLI adds:

| File | What it adds |
|------|--------------|
| `src/views/PricingPlansView.astro` | The page content |
| `src/pages/pricing-plans.astro` | Wrapper for the default language |
| `src/pages/[lang]/[...pricingPlans].astro` | Wrapper for other languages |
| `src/config/nav.config.ts` | A route and a nav item |
| `src/i18n/translations/*.ts` | Title and description strings, in every language file |

The names `index`, `blog`, `404`, `rss`, `search` and `lang` are reserved and skipped. Pages use `PageLayout`. Demo projects created through the wizard can choose `LandingLayout` instead.

## After Scaffolding

```bash
cd my-site
pnpm dev
```

Your site runs at `http://localhost:4321`.
