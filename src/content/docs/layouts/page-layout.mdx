`PageLayout` is used for standard content pages like About, Contact, and Services.

## Usage

```astro
---
import PageLayout from '@/layouts/PageLayout.astro';
---

<PageLayout title="About Us" description="Learn more about our team">
  <section class="py-16">
    <div class="container max-w-4xl">
      <h1 class="text-4xl font-bold mb-6">About Us</h1>
      <p class="text-foreground-muted">
        We build amazing things...
      </p>
    </div>
  </section>
</PageLayout>
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | — | Page title |
| `description` | `string` | — | Meta description |
| `image` | `string` | — | OG image URL |
| `imageAlt` | `string` | — | OG image alt text |
| `noindex` | `boolean` | `false` | Prevent search engine indexing |
| `nofollow` | `boolean` | `false` | Prevent link following |
| `searchable` | `boolean` | `true` | Include the page in [site search](/configuration/search/) |

## Features

### Fixed Header

Includes the standard `Header` with:

- Logo and navigation from `nav.config.ts`
- The CTA and actions from `headerConfig`
- Language switcher, when the site has more than one language
- Theme toggle
- Mobile menu

### Simple Footer

Includes `Footer` with the simple layout: links from `nav.config.ts`, social links and a copyright notice.

### Container Classes

Content is not wrapped in a container by default. Add your own:

```astro
<PageLayout title="Page">
  <section class="container py-16">
    <!-- Content with container -->
  </section>

  <section class="bg-surface-invert py-16">
    <div class="container">
      <!-- Full-width background, contained content -->
    </div>
  </section>
</PageLayout>
```

<Aside type="caution">
  `BaseLayout` already renders `<main>`. Don't add another one in your page content.
</Aside>

## Customizing Header and Footer

Change the defaults for the whole site in [`nav.config.ts`](/configuration/routes/#header-defaults). For a page that needs something different, use `BaseLayout` directly and render your own `Header` and `Footer`:

```astro
---
import BaseLayout from '@/layouts/BaseLayout.astro';
import Header from '@/components/layout/Header.astro';
import Footer from '@/components/layout/Footer.astro';
---

<BaseLayout title="Page">
  <Header slot="header" layout="minimal" />
  <!-- Content -->
  <Footer slot="footer" layout="columns" columns={3} />
</BaseLayout>
```
