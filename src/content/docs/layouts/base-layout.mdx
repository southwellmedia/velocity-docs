`BaseLayout` is the foundation that all other layouts extend. It provides the HTML document structure and core functionality.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `string` | — | Page title (required) |
| `description` | `string` | — | Meta description |
| `image` | `string` | — | OG image URL |
| `imageAlt` | `string` | — | OG image alt text |
| `article` | `object` | — | Article metadata |
| `noindex` | `boolean` | `false` | Prevent search indexing |
| `nofollow` | `boolean` | `false` | Prevent link following |
| `includeOrgSchema` | `boolean` | `false` | Include Organization JSON-LD |
| `alternates` | `{ locale, href }[]` | Matching route in each language | `hreflang` alternates |

### Article Metadata

```typescript
interface ArticleMetadata {
  publishedTime?: Date;
  modifiedTime?: Date;
  authors?: string[];
  tags?: string[];
}
```

## Slots

| Slot | Purpose |
|------|---------|
| `header` | Header component placement |
| `default` | Main page content |
| `footer` | Footer component placement |

## Usage

```astro
---
import BaseLayout from '@/layouts/BaseLayout.astro';
import SiteHeader from '@/components/site/SiteHeader.astro';
import SiteFooter from '@/components/site/SiteFooter.astro';
---

<BaseLayout
  title="Page Title"
  description="Page description"
>
  <SiteHeader slot="header" />

  <!-- Your content -->

  <SiteFooter slot="footer" />
</BaseLayout>
```

`SiteHeader` and `SiteFooter` in `src/components/site/` wrap Velocity's `Header` and `Footer` with your site's defaults. Every layout renders them, so render them here too rather than `Header` and `Footer` directly.

`BaseLayout` renders the page's only `<main id="main-content">` around the default slot, so don't add your own.

## Included Features

### Fonts

Fonts load through the [Astro Fonts API](/customization/fonts/) and are self-hosted:

- **Manrope** — Body text, preloaded
- **Outfit** — Headings
- **JetBrains Mono** — Monospace for code

### Language

`<html lang>`, `hreflang` links and the skip link all follow the current page's language. See [Internationalization](/configuration/i18n/).

### SEO Component

Automatically includes the `SEO` component with:

- Title and description meta tags
- Open Graph tags
- Twitter Card tags
- Canonical URL

### JSON-LD Schemas

Optional structured data:

```astro
<BaseLayout
  title="Home"
  includeOrgSchema
>
  <!-- Includes Organization schema -->
</BaseLayout>
```

### Theme Initialization

Prevents flash of incorrect theme:

```html
<script is:inline>
  // Runs before paint to set .dark class
</script>
```

### Analytics

If configured, includes:

- Google Analytics
- Google Tag Manager

The consent banner is also rendered on every page, and shows when `PUBLIC_CONSENT_ENABLED` is set.

### Page Transitions

Velocity uses native cross-document view transitions, set in `global.css`, and Astro's prefetch instead of a client router:

```css
@view-transition {
  navigation: auto;
}
```

Supporting browsers cross-fade between pages. Everyone else gets a normal page load. Animations finish instantly for visitors who prefer reduced motion.

<Aside type="note">
  Most pages should use `PageLayout`, `BlogLayout`, or `LandingLayout` instead of `BaseLayout` directly.
</Aside>

## Customizing

To add global elements, edit `BaseLayout.astro`:

This is a safe file, so upgrades replace it and save your version to `.velocity-backup/`. Reapply your changes after upgrading.

```astro
<head>
  <!-- Add scripts, meta tags, etc. -->
</head>

<body>
  <slot name="header" />
  <main id="main-content" class="flex-1">
    <slot />
  </main>
  <slot name="footer" />

  <!-- Add global modals, toast containers, etc. -->
</body>
```
