Velocity includes 5 layouts for different page types.

## Available Layouts

<CardGrid>
  <Card title="BaseLayout" icon="setting">
    Core HTML wrapper with SEO, fonts, and theme initialization. Other layouts extend this.
  </Card>
  <Card title="PageLayout" icon="document">
    Standard content pages with header and footer. Indexed by site search.
  </Card>
  <Card title="BlogLayout" icon="pencil">
    Blog articles with hero, breadcrumbs, and related posts.
  </Card>
  <Card title="LandingLayout" icon="rocket">
    Full-width landing pages with the standard header.
  </Card>
  <Card title="MarketingLayout" icon="star">
    Full-width marketing pages with a floating, inverted header.
  </Card>
</CardGrid>

## Layout Hierarchy

```
BaseLayout (core)
├── PageLayout (extends Base)
├── BlogLayout (extends Base)
├── LandingLayout (extends Base)
└── MarketingLayout (extends Base)
```

All layouts extend `BaseLayout`, which provides:

- HTML document structure, with the page's language in `<html lang>`
- The page's only `<main>` element
- Fonts through the Astro Fonts API
- Favicon and manifest
- SEO component and `hreflang` links
- JSON-LD schemas
- Analytics integration and the consent banner
- Theme initialization

## Quick Usage

Page content usually lives in a [view](/getting-started/project-structure/#pages-and-views) that picks a layout.

### Standard Page

```astro
---
import PageLayout from '@/layouts/PageLayout.astro';
---

<PageLayout title="About Us" description="Learn about our team">
  <section class="py-16">
    <h1>About Us</h1>
    <!-- Content -->
  </section>
</PageLayout>
```

### Blog Post

```astro
---
import BlogLayout from '@/layouts/BlogLayout.astro';
---

<BlogLayout
  title={post.data.title}
  description={post.data.description}
  publishedAt={post.data.publishedAt}
  author={post.data.author}
>
  <Content />
</BlogLayout>
```

### Landing Page

```astro
---
import LandingLayout from '@/layouts/LandingLayout.astro';
import { Hero } from '@/components/hero';
import CTA from '@/components/landing/CTA.astro';
---

<LandingLayout title="Welcome" description="Your landing page">
  <Hero>
    <h1 slot="title">Welcome</h1>
  </Hero>
  <CTA />
</LandingLayout>
```
