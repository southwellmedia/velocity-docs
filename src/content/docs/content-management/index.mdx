Velocity uses Astro's Content Layer API for type-safe content management.

## Content Collections

Collections are defined in `src/content.config.ts`:

- **blog** — Blog posts in MDX format
- **pages** — Static pages
- **authors** — Author profiles (JSON)
- **faqs** — FAQ entries (JSON)

## Directory Structure

```
src/content/
├── blog/
│   ├── en/
│   │   ├── first-post.mdx
│   │   └── second-post.md
│   ├── es/
│   │   └── primer-post.mdx
│   └── fr/
│       └── premier-post.mdx
├── pages/
├── authors/
│   └── team.json
└── faqs/
    └── general-en.json
```

## Querying Content

Use the helpers in `src/lib/blog.ts`. It's the only place that maps posts to URLs, and it handles languages and drafts:

```astro
---
import { getPosts, getPostUrl } from '@/lib/blog';

// Published posts for a language, newest first.
// Drafts are included in development.
const posts = await getPosts('en');

// Get featured posts
const featured = posts.filter((post) => post.data.featured);
---

{posts.map((post) => (
  <a href={getPostUrl(post)}>{post.data.title}</a>
))}
```

| Helper | Returns |
|--------|---------|
| `getPosts(locale)` | Published posts for a language, newest first |
| `getPostUrl(post)` | `/blog/my-post` or `/es/blog/my-post` |
| `getPostSlug(post)` | The slug, without the language folder |
| `getPostLocale(post)` | The language, from the folder or frontmatter |
| `getPostReadingTime(post)` | Reading time in minutes |

For other collections, use `getCollection()` from `astro:content`.

## Rendering Content

```astro
---
import { render } from 'astro:content';
import BlogLayout from '@/layouts/BlogLayout.astro';
import { getPosts, getPostSlug } from '@/lib/blog';

export async function getStaticPaths() {
  const posts = await getPosts();
  return posts.map((post) => ({
    params: { slug: getPostSlug(post) },
    props: { post },
  }));
}

const { post } = Astro.props;
const { Content } = await render(post);
---

<BlogLayout {...post.data}>
  <Content />
</BlogLayout>
```
